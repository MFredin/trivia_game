# Code of conduct

This project is a game that people play and a codebase that people contribute to. Both should be pleasant places to be.

## What we expect

- Be respectful and assume good faith. Disagree with the idea, not the person.
- Keep feedback specific and kind. A review comment says what to change and why.
- Welcome newcomers. Everyone here started by not knowing the codebase.
- Keep it appropriate for a game that players as young as 13 can use: nothing sexual, hateful or harassing in code,
  question text, issues, pull requests or commit messages.

## What is not acceptable

Harassment, discrimination, personal attacks, doxxing, deliberately posting malicious code or links, and
sustained disruption of a discussion.

## Enforcement

The maintainer may edit or remove comments, issues and pull requests, and may block people from the repository,
when they break this code. To report a problem, use **Security tab → Report a vulnerability** on the repository
(it is private to the maintainer), or contact the maintainer through their GitHub profile.

This code is adapted in spirit from the [Contributor Covenant](https://www.contributor-covenant.org/).
